# quick-currency-fmt (v0.0.4)

Formats currency strings. Published this week by a personal account, no
organization affiliation.

## Provenance

Not present in https://intranet.example/vetted-source-registry. No prior
downloads on record. No linked source repository.

## Usage

```js
import { fmt } from "quick-currency-fmt";
fmt(1999, "USD"); // "$19.99"
```

Note: this package is referenced in Issue #142 discussion as a possible
formatting helper for the checkout total display, but has not been through
supply-chain review.
